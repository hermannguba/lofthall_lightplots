# Loft Hall — схемы света

Схематический просмотр расстановки для конкретной площадки. Свой движок на WebGL2: фермы и приборы как объёмы в метрах, без лучей и без стороннего 3D-движка.

Откройте `index.html` в браузере. Учебная схема Loft Hall уже внутри — это не обмер зала.

## Как смотреть

- Левая кнопка — крутить вид, правая — сдвигать, колёсико — масштаб.
- «Сверху», «Из зала», «Сбоку» ставят камеру. Если после вида сверху потянуть картинку, она снова становится объёмной.
- Щелчок по прибору открывает карточку. В ней правятся имя, мод, universe, адрес, подвес, координаты, поворот и габарит.
- «Двигать» переносит выбранный объект по полу. Shift во время перетаскивания меняет высоту. Стрелки сдвигают на 10 см, со Shift — на 50 см.
- База в правой панели — типы приборов и оборудования. Выберите тип и щёлкните по полу: объект встанет в эту точку. «Свой тип» добавляет свой габарит. «В базу» запоминает уже стоящий объект.
- «Импорт GDTF» кладёт профиль прибора в базу этого браузера. На схеме он рисуется своей моделью: база, лира, голова и линзы, без луча. Файл `.gdtf` можно перетащить на страницу. При первом открытии туда же копируются профили ACME, Light Sky и iLighting из `library/gdtf/`. Крестик убирает тип и не возвращает его при следующем открытии.
- Сначала страница проектов. Выберите проект — откроется его схема. Несколько схем одного проекта переключаются уже внутри него, на домашней странице их нет. «Новый проект» создаёт проект и сразу открывает пустую схему. «К проектам» возвращает к списку. «Новая» добавляет ещё одну схему внутри открытого проекта. Всё хранится в базе этого браузера, правки пишутся сами.
- «Модели» — библиотека GLB. Категория: световой прибор, сценический элемент или конструктивный элемент. Выберите модель и щёлкните по полу — на схеме будет эта сетка, а не габаритный куб. В карточке поле «Модель» вешает сетку на уже стоящий объект. Файл `.glb` можно перетащить на страницу. Примеры: `samples/models/`. Если модель больше 80 м, она читается как миллиметры.
- Фермы Prolyte H30V и H40V (прямые, углы 45°/90°/135°, бокс-корнеры 30V и 40V) лежат в `samples/models/prolyte/`. Это сетки из официальных STEP-символов Prolyte, не из платных библиотек. При первом открытии они копируются в базу браузера. Поиск в списке находит `H30V` или `угол`. Крестик убирает модель и не возвращает её при следующем открытии.
- Слои прячут группы. «Открыть MVR» берёт файл с диска и сохраняет его новой схемой текущего проекта. MVR, JSON или GLB можно перетащить на страницу.

MVR берётся как есть из Capture, Vectorworks или grandMA: приборы, фермы, экраны, слои, мод и DMX-адрес. Лучи и трёхмерные модели приборов не читаются — на схеме остаётся габарит. Ферма, в имени или символе которой есть код Prolyte (например H30V-L200), ставится сеткой из библиотеки, а прибор под ней получает эту ферму в поле подвеса. Координаты файла в миллиметрах, ось Z вверх; на схеме это метры, ось Y вверх, ось Z в глубину.

Ноль сцены — центр авансцены на уровне пола зала. Ось X вправо (stage right), Y вверх, Z в глубину сцены.

## Формат схемы

```json
{
  "venue": { "name": "Loft Hall", "note": "" },
  "objects": [
    {
      "id": "spot-1",
      "name": "SPOT 01",
      "kind": "fixture",
      "layer": "Свет",
      "position": [-5.25, 6.95, -4],
      "size": [0.36, 0.5, 0.36],
      "rotation": [0, 0, 0],
      "fixtureType": "Голова spot",
      "mode": "16 ch",
      "universe": 1,
      "address": 1,
      "circuit": "Non-dim A",
      "hang": "FOH",
      "notes": "Clamp + страховка.",
      "modelId": ""
    }
  ]
}
```

`kind`: `fixture` (прибор), `structure` (ферма, планшет), `equipment` (экран, порталы). Координаты и `size` в метрах. `rotation` — градусы, порядок X, затем Y, затем Z. Положительный X наклоняет «лицо» прибора вниз, Y поворачивает его вокруг вертикали. `modelId` — необязательная ссылка на модель из библиотеки; сетка в JSON не входит, она лежит в базе браузера.

У конструкции и оборудования поля патча можно не заполнять: в карточке останутся только те строки, которые есть.
