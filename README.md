# Loft Hall — схемы света

Схематический просмотр расстановки для конкретной площадки. Свой движок на WebGL2: фермы и приборы как объёмы в метрах, без лучей и без стороннего 3D-движка.

Откройте `index.html` в браузере. Учебная схема Loft Hall уже внутри — это не обмер зала.

## Как смотреть

- Левая кнопка — крутить вид, правая — сдвигать, колёсико — масштаб.
- «Сверху», «Из зала», «Сбоку» ставят камеру. Если после вида сверху потянуть картинку, она снова становится объёмной.
- Щелчок по прибору открывает карточку. В ней правятся имя, мод, universe, адрес, подвес, координаты, поворот и габарит.
- «Двигать» переносит выбранный объект по полу. Shift во время перетаскивания меняет высоту. Стрелки сдвигают на 10 см, со Shift — на 50 см.
- База в правой панели — типы приборов и оборудования. Выберите тип и щёлкните по полу: объект встанет в эту точку. «Свой тип» добавляет свой габарит. «В базу» запоминает уже стоящий объект.
- Слои прячут группы. «Открыть MVR» берёт файл с диска; MVR или JSON можно перетащить на страницу.

MVR берётся как есть из Capture, Vectorworks или grandMA: приборы, фермы, экраны, слои, мод и DMX-адрес. Лучи и трёхмерные модели приборов не читаются — на схеме остаётся габарит. Координаты файла в миллиметрах, ось Z вверх; на схеме это метры, ось Y вверх, ось Z в глубину.

Ноль сцены — центр авансцены на уровне пола зала. Ось X вправо (stage right), Y вверх, Z в глубину сцены.

## Формат схемы

```json
{
  "venue": { "name": "Loft Hall", "note": "" },
  "objects": [
    {
      "id": "spot-1",
      "name": "SPOT 01",
      "kind": "fixture",
      "layer": "Свет",
      "position": [-5.25, 6.95, -4],
      "size": [0.36, 0.5, 0.36],
      "rotation": [0, 0, 0],
      "fixtureType": "Голова spot",
      "mode": "16 ch",
      "universe": 1,
      "address": 1,
      "circuit": "Non-dim A",
      "hang": "FOH",
      "notes": "Clamp + страховка."
    }
  ]
}
```

`kind`: `fixture` (прибор), `structure` (ферма, планшет), `equipment` (экран, порталы). Координаты и `size` в метрах. `rotation` — градусы, порядок X, затем Y, затем Z. Положительный X наклоняет «лицо» прибора вниз, Y поворачивает его вокруг вертикали.

У конструкции и оборудования поля патча можно не заполнять: в карточке останутся только те строки, которые есть.
